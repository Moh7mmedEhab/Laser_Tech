# Skills

## Auto Skill Pack (from project-standards)

Recorded at setup; these workflows were applied inline where relevant:

- **grill-me** — requirements interview (done in planning; stack, taste, CRUD shape, currency, login flavor all confirmed with the user)
- **taste / frontend-design** — design tokens from details.json, reference-quality density, no generic look
- **writing-plans / executing-plans** — plan approved by user, executed one commit at a time
- **verification-before-completion** — `npm run build` (type-check) verified at each milestone

Other pack skills (TDD, systematic-debugging, worktrees, subagent-driven development) are available and will be used when the task calls for them.
